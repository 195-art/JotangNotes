## 任务 2

1. **为什么 Agent 能读写文件？**  
   因为运行环境为它提供了文件读写等工具及权限。普通聊天 AI 没有这些工具，只能根据聊天内容回答。

2. **Tool 有什么作用？**  
   Tool 让 Agent 能实际读取文件、修改代码、执行命令，并根据结果继续工作。

3. **为什么需要“员工手册”？**  
   告诉 Agent 项目用途、组织方式和操作规范，减少误解与错误修改。

4. **为什么会忘记？额度怎么算？**  
   上下文容量有限，对话过长可能被压缩或遗漏。额度与请求数、Token等有关。

5. **随意执行终端命令有什么风险？**  
   可能误删文件、破坏配置、泄露敏感信息或运行不可信程序，因此应限制权限并检查重要操作。
